# Mrasante Quarkus-rest

## How do I install these formulae?

`brew install mrasante/quarkus-rest/<formula>`

Or `brew tap mrasante/quarkus-rest` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mrasante/quarkus-rest"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
